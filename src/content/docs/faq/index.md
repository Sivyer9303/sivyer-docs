### Q1. 提示「无效的令牌 / Invalid API Key / 401」

**可能原因：**

- Key 复制少了字符，或多了空格
- Key 已被删除 / 禁用
- 客户端填错了 Key 字段

**解决办法：**

1. 回控制台重新复制 Key
2. 确认 Key 状态为「启用」
3. 重新粘贴到客户端（先清空再粘贴）
4. 仍不行就 **新建一个 Key** 再试

---

### Q2. 提示「无权访问 xxx 分组 / 403」

**可能原因：**

- 创建 Key 时选的分组，和当前请求所需分组不一致
- 用户账号没有该分组权限
- 客户端指定了某个分组相关模型，但 Key 不在该分组

**解决办法：**

1. 看报错里的分组名（例如 `claude`）
2. 编辑或重建 Key，**明确选择该分组**
3. 若下拉框里根本没有该分组，联系站长给你账号开通对应分组权限
4. 不要混用：Claude 模型配 OpenAI 分组的 Key

### Q3. 提示「额度不足 / 余额不足 / 429 / quota」

**解决办法：**

1. 登录控制台查看余额
2. 去充值
3. 检查该 Key 是否单独设置了过小的「剩余配额」
4. 充值后稍等片刻再重试
5. 生图（尤其 4K）消耗通常高于纯文本，余额不足时优先检查这一项

---

### Q4. 提示「无可用渠道 / 模型不存在 / model not found」

**可能原因：**

- 模型名写错（大小写、少了日期后缀）
- Key 所在分组没有该模型对应渠道
- 该模型临时下线

**解决办法：**

1. 打开 [定价页](https://www.sivyer.cc/pricing) 或「模型广场」，**原样复制模型名**
2. 确认 Key 分组与该模型所属线路一致
3. 换一个同分组下明确可用的模型测试
4. 仍不行时，换时段或联系站长确认渠道状态

---

### Q5. 能连上网，但一直超时 / 无响应

**解决办法：**

1. 浏览器直接打开 `https://www.sivyer.cc`，确认网站本身可访问
2. 检查本地网络、公司代理、VPN 是否干扰
3. 关闭系统代理后再试；或相反，若必须翻墙才能访问再开启
4. 在 CC Switch / Cherry Studio 中检查 Base URL 是否多写了路径
5. 用 [配置中转站](/configure/) 中的 `curl` 命令排除「是不是客户端问题」
6. **生图 / 4K** 请求更久，更容易超时：可适当加大客户端超时、换非高峰时段，或先用 `1K`/`2K` 验证链路

---

### Q6. Cherry Studio 检测失败

**排查顺序：**

1. API 地址是否为 `https://www.sivyer.cc`（带 `https://`）
2. 是否误填成带 `/v1/chat/completions` 的完整接口
3. Key 是否正确、分组是否匹配
4. 右上角启用开关是否打开
5. 若以前填过旧地址，把非默认协议里的旧地址清空后再测

---

### Q7. CC Switch 已启用，但 Claude Code 仍走官方或旧配置

**解决办法：**

1. 确认 CC Switch 中该供应商已处于 **启用** 状态
2. **关掉旧终端，新开一个终端** 再运行 `claude`
3. 检查 `~/.claude/settings.json` 是否已被写入本站地址
4. 若有多个配置工具同时改同一文件，先统一只用一个工具，避免互相覆盖

---

### Q8. macOS 打不开软件（身份不明的开发者）

**解决办法：**

1. 系统设置 → 隐私与安全性 → 仍要打开
2. 或右键应用 → 打开
3. 确认安装包来自官方 GitHub / 官网，而不是来路不明的修改版

---

### Q9. Windows 安装时被拦截

**解决办法：**

1. SmartScreen 点「更多信息」→「仍要运行」
2. 临时允许杀毒软件放行该安装包
3. 改用官方提供的 Portable（便携版）

---

### Q10. 不知道自己的 Mac 该下 arm64 还是 x64

**解决办法：**

- 苹果菜单 → 关于本机
- 有「Apple M1/M2/M3/M4」→ 下 **arm64**
- 写着 Intel → 下 **x64**
- 下错通常也能装，但可能打不开或性能异常，请下对应版本

---

### Q11. Key 泄露了怎么办？

1. 立刻登录控制台
2. **禁用或删除** 泄露的 Key
3. 重新创建新 Key
4. 在所有客户端里替换为新 Key
5. 检查近期用量是否有异常消耗

---

### Q13. Cherry Studio「绘画」页找不到模型 / 提示暂无图片模型

**解决办法：**

1. 确认已在 NewAPI 服务商下添加了生图模型
2. 将该模型 **端点类型** 改为 **「图像生成（OpenAI）」**
3. 返回绘画页重新选择服务商
4. 或到「设置 → 默认模型 → 绘画模型」指定默认图像模型

---

### Q14. 为什么我怎么调都生不出 4K？

**最常见原因：** 只在「绘画」页改尺寸，而默认绘画工具 **没有 4K 选项**。

**正确做法：**

1. 换用支持高分辨率档位的 **对话生图模型**（以本站模型列表为准）
2. 按 [生图详解](/cherry-studio/image-generation/) 中的「手动设置 4K」 给助手添加：
   - `imageConfig`：`{ "aspectRatio": "16:9", "imageSize": "4K" }`
   - `responseModalities`：`["TEXT", "IMAGE"]`
3. 在对话里发画图指令，而不是只在绘画页点生成
4. 出图后查看图片属性确认分辨率
5. 确认 Cherry Studio 为较新版本

---

### Q15. 我把质量调成 high，为什么还是不够清晰？

**因为质量（quality）和分辨率（imageSize / size）不是一回事：**

- `high`：采样更细，细节更好一点  
- `4K`：像素数量显著增加，才是真正的高分辨率

要高清壁纸级别，请同时关注：

1. `imageSize` / 尺寸是否为 `4K`（或足够大的像素）
2. 比例是否正确
3. 提示词是否写清细节与光线

---

### Q16. 生图成功了但很慢 / 中途失败

**解决办法：**

1. 4K 本身更慢，先用 `1K` 或 `2K` 验证提示词
2. 生成数量先设为 1
3. 尝试关闭流式输出后再生成
4. 检查网络与代理，避免长请求被中途断开
5. 看控制台是否已扣费：若已扣费但客户端没显示，到聊天记录/画板里找，或换非流式重试
