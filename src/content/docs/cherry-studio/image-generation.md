本章专门讲 **如何用 Cherry Studio 通过本站中转站画图**。  
请先完成 [配置中转站](/configure/)，确保 NewAPI 服务商已配置成功、Key 有额度。

> ⚠️ **先看结论（很重要）**
>
> 1. Cherry Studio 里生图有 **两条路**：内置 **「绘画」应用**，以及 **对话里用多模态生图模型**（如 Gemini 图片模型）。
> 2. **内置「绘画」默认参数面板，通常只能选到常见尺寸（如 1024×1024 等），默认不支持真正的 4K。**
> 3. 想稳定出 **4K**，一般需要走 **对话助手 + 手动添加自定义参数**（见下方 6.4），不要只指望「绘画」页默认选项。
> 4. 官方文档也写明：Gemini 类图片生成要在 **对话界面** 使用，且界面本身往往 **不直接提供参数调节**，所以 4K / 比例要靠自定义参数补上。

### 6.1 生图前准备：让模型真正能「画画」

#### 6.1.1 确认中转站有可用的生图模型

1. 打开本站 [定价页 / 模型广场](https://www.sivyer.cc/pricing)
2. 找名称里带 `image`、`gpt-image`、`dall-e`、`flux`、`banana`、`gemini-*-image` 等字样的模型
3. 记下 **完整模型名** 和它所属 **分组**
4. 创建/选择 Key 时，分组要与该生图模型一致（否则会 403 或无渠道）

> 📷【请替换图片】  
> **图 6-1：定价页中的生图模型**  
> 圈出本站实际可用的图片模型名称与分组提示

#### 6.1.2 在 Cherry Studio 里正确添加生图模型

打开 **设置 → 模型服务 → New API**（你已配置好的本站服务商）：

**路径 A：OpenAI 兼容「绘画」页模型（走 `/v1/images/generations`）**

1. 获取或手动添加生图模型（如 `gpt-image-2` 等，以本站实际为准）
2. 点击该模型右侧 **编辑**
3. 把 **端点类型** 设为 **「图像生成（OpenAI）」**
4. 保存

> 不做这一步，模型可能只出现在聊天里，或在绘画页提示「暂无可用的图片生成模型」，甚至报 `Invalid JSON response`。

**路径 B：Gemini / 多模态对话生图模型（推荐用于 4K）**

1. 添加 Gemini 图片相关模型（名称以本站为准，常见类似 `gemini-*-image*`）
2. 提供商类型若支持，可按模型要求选择 **Gemini** 相关类型（以 Cherry Studio 当前版本界面为准）
3. 这类模型通常在 **对话** 里出图，而不是只靠「绘画」页默认面板

### 6.2 方式一：使用内置「绘画」应用（适合日常快速出图）

#### 6.2.1 如何进入绘画页

1. 打开 Cherry Studio
2. 点击顶部标签栏右侧 **「+」**，打开 **启动台**
3. 选择 **「绘画」**
4. 页面大致分为：
   - 左侧：画板列表
   - 中间：画布（生成结果）
   - 底部：提示词输入、服务商/模型选择、参数区

> 📷【请替换图片】  
> **图 6-3：启动台中的「绘画」入口**

> 📷【请替换图片】  
> **图 6-4：绘画页面总览**  
> 标注：服务商、模型、提示词框、参数面板、生成按钮

#### 6.2.2 基础出图步骤

1. 在底部选择已配置的 **本站服务商（New API）**
2. 选择端点类型已设为「图像生成」的模型
3. 输入提示词，例如：

```text
一只戴着圆眼镜的橘猫坐在书堆上，复古油画风格，温暖的黄昏光线，细节清晰
```

4. 在右侧/下方参数区调整 **尺寸、质量、比例、数量** 等（见下一节）
5. 点击 **生成**，等待数秒到几十秒
6. 在画布中预览，可下载 / 收藏 / 再画一张

若提示「暂无可用的图片生成模型」，点绿色 **「去设置」**，回到该服务商下补加图像生成模型。

也可到 **设置 → 默认模型 → 绘画模型**，指定一个默认图像模型，省得每次手选。

### 6.3 绘画页参数怎么设：分辨率、质量、比例（重点）

不同模型显示的参数名可能略有差异。下面按「你在界面上最常看到的选项」说明。

#### 6.3.1 分辨率 / 图片尺寸（Size）

| 常见选项 | 含义 | 适合场景 |
| --- | --- | --- |
| `自动` / `auto` | 交给模型或网关默认 | 新手先试通 |
| `1024x1024` | 约 1K 正方形 | 头像、配图、最常用 |
| `1024x1536` / `1536x1024` | 竖图 / 横图 | 手机壁纸、横幅 |
| `1024x1792` / `1792x1024` | 更长的竖/横 | 海报长图 |
| `512x512` / `256x256` | 小图 | 快速草稿、省额度 |

**小白建议：**

- 日常先用 `1024x1024`
- 尺寸越大通常越慢、越贵
- **「绘画」页常见下拉项到 1K～2K 像素档为止，默认往往没有真正的 4K 选项**

> 📷【请替换图片】  
> **图 6-5：绘画页「图片尺寸 / 分辨率」下拉框**  
> 圈出当前可选尺寸；若没有 4K，请在图注写明「默认无 4K」

#### 6.3.2 生成质量（Quality）

| 常见选项 | 含义 | 说明 |
| --- | --- | --- |
| `自动` / `auto` | 默认质量 | 先连通时用这个 |
| `low` | 低质量 | 更快、更省，细节少 |
| `medium` | 中等质量 | 平衡速度与效果 |
| `high` | 高质量 | 细节更多，更慢、更耗额度 |

> **注意：**  
> - **质量 ≠ 分辨率。** `high` 只是采样更精细，**不会 magically 变成 4K**。  
> - 要 4K 请看 6.4；质量参数是否生效，还取决于模型本身是否支持（有的模型忽略 `quality`）。

> 📷【请替换图片】  
> **图 6-6：绘画页「质量 Quality」选项**

#### 6.3.3 比例 / 宽高比（Aspect Ratio）

比例决定画面是方的、竖的还是宽的。常见选项：

| 比例 | 观感 | 常见用途 |
| --- | --- | --- |
| `1:1` | 正方形 | 头像、封面小图 |
| `3:4` / `4:3` | 略竖 / 略横 | 常规插画 |
| `2:3` / `3:2` | 更竖 / 更横 | 摄影构图 |
| `9:16` | 竖长屏 | 手机壁纸、短视频封面 |
| `16:9` | 横宽屏 | 电脑壁纸、横版海报 |
| `21:9` | 超宽 | 电影感横图 |

在「绘画」页里，有的模型用 **尺寸像素**（如 `1024x1792`）间接表达比例；有的会单独给 **宽高比** 下拉。二者选一种能生效的即可，不要互相冲突地乱填。

#### 6.3.4 其他常见参数（了解即可）

| 参数 | 建议 | 说明 |
| --- | --- | --- |
| 生成数量 / 批次数 | 新手先 `1` | 一次多张更费额度 |
| 步数 Steps | `20`～`30` | 太高提升有限 |
| CFG / Guidance | `7`～`12` | 越高越「听话」，太高可能死板 |
| 种子 Seed | 留空=随机；填固定数可复现 | 调参对比时很有用 |
| 敏感度等 | 保持默认 | 除非模型文档有特殊要求 |

#### 6.3.5 为什么默认绘画工具「出不了 4K」？

原因通常是下面几条叠在一起：

1. **「绘画」页走的是 OpenAI Images 一类协议**，界面尺寸枚举多为 `1024x1024`、`1792x1024` 等，**没有 `4K` 这一档**
2. 部分模型即便支持更大分辨率，Cherry Studio 默认下拉也 **不会把 4K 列出来**
3. Gemini 等多模态生图被官方说明为应在 **对话** 使用，且 **界面不支持直接调参**，所以默认路径更容易一直停在 1K

因此：

- 只要「能出图、够用」→ 用本节「绘画」页即可  
- 要 **明确 4K / 指定比例** → 必须按 **6.4 手动设置**

### 6.4 方式二：手动设置 4K（以及自定义比例）——必看

适用场景：

- 要用 Gemini / banana / 同类 **对话生图** 模型
- 需要 `1K` / `2K` / `4K` 分辨率档位
- 需要精确比例，如 `9:16`、`16:9`、`21:9`

> 请尽量使用 **较新版本的 Cherry Studio**，旧版自定义参数兼容性较差。

#### 6.4.1 步骤总览

1. 确认助手使用的是 **支持生图的模型**（本站定价页核对）
2. 编辑该助手，添加自定义参数 `imageConfig`、`responseModalities`
3. 在对话里直接发送画图指令
4. 生成后右键查看图片属性，确认是否达到 4K

#### 6.4.2 详细操作

1. 回到 Cherry Studio **首页 / 对话**
2. 左侧找到你要用的 **助手**（没有就新建一个，例如命名为「4K生图助手」）
3. 点击助手旁的 **「...」** → **「编辑助手」**
4. 在助手设置里选择要用来生图的模型（本站 NewAPI 下的图片模型）
5. 找到底部 **「自定义参数」**，点击 **「+ 添加参数」**
6. 依次添加下面两个参数（类型选 **JSON**）：

**参数 1：分辨率 + 比例**

| 项 | 填写 |
| --- | --- |
| 参数名 | `imageConfig` |
| 类型 | `JSON` |
| 值 | 见下方示例 |

示例（竖屏 4K）：

```json
{
  "aspectRatio": "9:16",
  "imageSize": "4K"
}
```

横屏 4K 可改成：

```json
{
  "aspectRatio": "16:9",
  "imageSize": "4K"
}
```

正方形 4K：

```json
{
  "aspectRatio": "1:1",
  "imageSize": "4K"
}
```

**参数 2：允许返回图片（必填）**

| 项 | 填写 |
| --- | --- |
| 参数名 | `responseModalities` |
| 类型 | `JSON` |
| 值 | `["TEXT", "IMAGE"]` |

7. 保存助手设置  
8. 若界面有「流式输出」相关选项，部分教程建议生图时选 **非流式**（以你当前版本实测为准；出图异常时可关掉流式再试）  
9. 回到对话，发送例如：

```text
请生成一张超清照片：夜晚的赛博朋克城市街道，霓虹灯倒映在湿润地面，电影级光影
```

10. 出图后，在图片上右键 / 查看属性，确认分辨率是否接近 4K 档（例如长边约 3000～4000 像素，视比例而定）

#### 6.4.3 `imageSize` / `aspectRatio` 可用值速查

**分辨率 `imageSize`（常见）：**

| 值 | 说明 |
| --- | --- |
| `"1K"` | 约 1K，快、省 |
| `"2K"` | 更清晰 |
| `"4K"` | 最高清，更慢、更费，请耐心等待 |
| `"512px"` | 部分模型支持的较小档（若报错可不用） |

**比例 `aspectRatio`（常见）：**

`1:1`、`2:3`、`3:2`、`3:4`、`4:3`、`4:5`、`5:4`、`9:16`、`16:9`、`21:9`  
（部分上游还支持更极端比例如 `1:4`、`4:1` 等；若不支持会报错，换回上表即可）

#### 6.4.4 想同时保留「日常 1K」和「出图 4K」怎么办？

建议建 **两个助手**：

| 助手名 | imageSize | 用途 |
| --- | --- | --- |
| 日常聊天 | 不配 / `1K` | 普通对话 |
| 4K生图助手 | `4K` | 专门画高清图 |

这样不会每次改参数，也避免聊天助手一直按 4K 计费。

### 6.5 两种生图方式怎么选？

| 对比项 | 内置「绘画」页 | 对话助手 + 自定义参数 |
| --- | --- | --- |
| 上手难度 | 更简单 | 多几步，但一次配好 |
| 调尺寸/质量 | 界面下拉直接选 | 写在 `imageConfig` 里 |
| 是否容易出 4K | **默认基本不行** | **推荐，可明确写 `"4K"`** |
| 适合模型 | OpenAI Images 类 | Gemini 等多模态生图 |
| 推荐场景 | 日常 1K 配图 | 壁纸、海报、要高清细节 |

### 6.6 生图提示词小技巧

1. 写清楚：**主体 + 环境 + 风格 + 光线 + 镜头/构图**
2. 需要中文也能画，但很多模型英文提示更稳
3. 一次只强调 1～2 个核心主体，别堆太多无关物体
4. 4K 更吃提示词质量：把「材质、光影、细节」写具体
5. 不满意就固定 Seed（若有），只改一句描述做对比
