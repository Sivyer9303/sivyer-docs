### 2.1 打开网站

在浏览器地址栏输入：

```text
https://www.sivyer.cc
```

建议使用 **Chrome / Edge / Safari**，并收藏该网址。

### 2.2 注册账号

1. 点击右上角 **Sign in / 登录**（若界面已是中文，显示为「登录」）
2. 若没有账号，按页面提示进行 **注册**
3. 按要求填写邮箱 / 用户名 / 密码（以站点实际页面为准）
4. 注册成功后登录进入 **控制台（Console）**

### 2.3 充值 / 确认额度（如需要）

使用前请确认账户有可用额度：

1. 在控制台查看余额 / 剩余配额
2. 若余额为 0，按站点提供的充值入口完成充值
3. 充值到账后再创建 Key、配置工具

> Key 只是「钥匙」，没有额度就像有钥匙但车上没油，请求仍会失败。
