## 快速入口

<CardGrid stagger>
	<Card title="注册与登录" icon="rocket">
		打开 [www.sivyer.cc](https://www.sivyer.cc)，完成注册并确认余额。
		查看 [注册与登录](/getting-started/register/)。
	</Card>
	<Card title="创建 API Key" icon="approve-check">
		在控制台创建密钥，并按用途选择正确分组。
		查看 [创建 Key 与分组](/getting-started/create-key/)。
	</Card>
	<Card title="配置客户端" icon="setting">
		用 Cherry Studio / CC Switch 一键配置，或自行手改。
		查看 [配置中转站](/configure/)。
	</Card>
	<Card title="Cherry Studio 生图" icon="document">
		设置分辨率、质量、比例；默认绘画不出 4K 时用手动参数。
		查看 [生图详解](/cherry-studio/image-generation/)。
	</Card>
</CardGrid>
