## 通用清单

1. [ ] 已有 Base URL 与 API Key  
2. [ ] 账户有余额  
3. [ ] Key 已启用，分组与目标模型一致  
4. [ ] 客户端里的地址没有多写 `/chat/completions`  
5. [ ] Key 无首尾空格、未截断  
6. [ ] 模型名与定价页完全一致  
7. [ ] 能收到一次成功回复 / 成功出图  
8. [ ] （可选）控制台用量有新增  

## 快速连通性测试（OpenAI 兼容）

把占位符换成你的值：

```bash
curl {{API_BASE_URL}}/v1/chat/completions \
  -H "Authorization: Bearer sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "{{MODEL_NAME}}",
    "messages": [{"role": "user", "content": "你好，请只回复：配置成功"}]
  }'
```

返回正常 JSON 且含模型回复，说明网关、Key、分组基本通了。
