API Key（有的版本叫「令牌 / Token」）是调用中转站的凭证，**等同于密码**，请妥善保管。

### 4.1 进入 API 密钥页面

1. 登录 [https://www.sivyer.cc](https://www.sivyer.cc)
2. 进入 **控制台（Console）**
3. 在左侧菜单找到：
   - **API 密钥**，或
   - **令牌**，或
   - 直接访问类似 `/console/token`、`/keys` 的路径（以你站点实际菜单为准）

### 4.3 必填 / 重要字段说明

| 字段 | 怎么填 | 说明 |
| --- | --- | --- |
| **名称** | 如：`我的电脑-Cherry`、`ClaudeCode专用` | 方便以后区分用途 |
| **分组** | **必须按用途正确选择**（见下一节） | 决定你能用哪些模型/渠道，以及计费倍率 |
| **过期时间** | 可留空或选「永不过期」 | 新手建议先不设过期，避免忘记 |
| **额度 / 配额** | 可先开「无限额度」（仍受账户总余额限制） | 或给单个 Key 设上限，防止误刷 |
| **模型限制** | 新手建议先留空 | 留空 = 不额外限制模型 |
| **IP 白名单** | 新手建议先留空 | 填错会导致自己都连不上 |

### 4.4 如何选择对应的分组（非常重要）

**分组**决定了：

1. 你的 Key 能访问哪些上游渠道 / 模型
2. 扣费倍率可能不同
3. 选错分组会出现「无权访问 xxx 分组」「无可用渠道」「模型不存在」等报错

#### 选择原则（小白版）

1. 先想清楚自己要干什么：
   - 主要用 **Claude / Claude Code** → 选 Claude 相关分组
   - 主要用 **GPT / Codex / OpenAI 兼容** → 选 OpenAI 相关分组
   - 主要用 **Gemini** → 选 Google / Gemini 相关分组
   - 主要用 **国产模型（如 DeepSeek 等）** → 选国模相关分组
2. 打开本站价格页对照：  
   [https://www.sivyer.cc/pricing](https://www.sivyer.cc/pricing)  
   每个模型下方通常会标注所属线路/分组说明（如 ClaudeCode、OpenAi、Google、国模等）
3. 在创建 Key 的「分组」下拉框中，选择与目标模型一致的分组
4. 若站点提供 **`auto` 分组**：
   - 适合「自动挑选可用渠道」的场景
   - 但如果你明确只要某一类模型，**手动指定对应分组更稳妥**

#### 分组选择示例（请按你站点实际名称对照修改）

| 你的用途 | 建议选择的分组类型 | 备注 |
| --- | --- | --- |
| Claude Code 编程 | ClaudeCode 相关分组（如 Max / kiro 等） | 以控制台实际可选名为准 |
| ChatGPT / Codex | OpenAI 相关分组 | Base URL 常配合 `/v1` |
| Gemini | Google / Gemini 相关分组 | |
| DeepSeek 等国产模型 | 国模相关分组 | |
| 不确定、想自动容灾 | `auto`（若有） | 仍建议先弄清账户权限 |

> **特别提醒：**  
> 即使用户账户有某个分组权限，**创建 Key 时也必须勾选/选择该分组**。  
> 只给用户开了权限、Key 没选对应分组，仍可能报：`无权访问 xxx 分组`。

### 4.5 保存并复制 Key

1. 确认名称、分组无误后，点击 **提交 / 保存**
2. 在列表中找到刚创建的 Key
3. 点击 **复制**（完整 Key 通常形如 `sk-xxxxxxxx`）
4. 先粘贴到一个本地记事本临时保存（不要发到微信群/公开聊天）

> 🔐 **安全提醒**
>
> - Key = 密码，泄露他人就能花你的钱
> - 不要把 Key 发到公开群、截图原样发给陌生人
> - 怀疑泄露：立刻在控制台 **删除/禁用旧 Key**，再新建一个

部分 NewAPI 页面还支持：

- **复制连接信息**（把地址 + Key 一起复制，方便导入客户端）
- **一键发送到支持的客户端**

若你看到这些按钮，也可以使用。
