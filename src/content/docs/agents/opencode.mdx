## 适合谁

使用 OpenCode 作为 AI CLI / Agent 工具链，并希望统一管理供应商的用户。

## 安装

本工具通过 npm 全局安装。若还没有 Node.js / npm，先完成 [安装 Node.js 与 npm](/basics/nodejs-npm/)。

```bash
npm install -g opencode-ai
```

（包名以官方当前发布为准。）

## 前置条件

- API Key 与 `{{API_BASE_URL}}`  
- 推荐先配置 [AI Toolbox](/config-manager/ai-toolbox/)  

## 方式一：AI Toolbox（推荐）

进入 OpenCode 的供应商列表添加渠道并保存；OpenAI 兼容地址常见为 `{{API_BASE_URL}}/v1`。模型在卡片的 **模型列表** 里获取并设置，再按该工具的方式启用。详见 [AI Toolbox](/config-manager/ai-toolbox/)。

也可以用 CC Switch：

<Steps>

1. 添加供应商并勾选 **OpenCode**
2. 填写 Key、`{{API_BASE_URL}}`、默认模型
3. 启用
4. 新开终端后再用 OpenCode

</Steps>

配置通常写入用户级：

- macOS / Linux：`~/.config/opencode/opencode.json`
- Windows：`%USERPROFILE%\.config\opencode\opencode.json`

## 方式二：手动配置

在 `opencode.json` 的 provider 块中填写：

- base URL：`{{API_BASE_URL}}`  
- api key  
- model：`{{MODEL_NAME}}`  

保存后重启终端 / 重启 OpenCode。

## 验证

1. 启动 OpenCode  
2. 发起一次简单任务  
3. 确认响应来自你的网关（可通过控制台用量观察）  

## 常见问题

- **与 Claude Code 配置互相覆盖**：尽量用 AI Toolbox 统一管理，避免手改多处  
- **模型名错误**：与服务商列表保持一致
