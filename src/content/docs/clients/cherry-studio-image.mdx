## 先看结论

1. Cherry Studio 生图有两条路：**内置「绘画」页**，以及 **对话里用多模态生图模型**  
2. **默认「绘画」参数面板通常只有常见尺寸（如 1024×1024），默认不支持真正的 4K**  
3. 要稳定出 **4K**，请用 **助手自定义参数**（见下文），不要只改绘画页下拉框  
4. Gemini 类生图通常在 **对话界面** 使用，界面本身往往不能直接调分辨率  

请先完成 [Cherry Studio 聊天](/clients/cherry-studio/) 的服务商配置。

## 生图前准备

1. 在服务商定价页找到带 `image` / `gpt-image` / `gemini-*-image` 等字样的模型  
2. Key 分组要包含该模型  
3. OpenAI Images 类模型：在 Cherry 里把端点类型设为 **「图像生成（OpenAI）」**

![端点类型改为图像生成](/screenshots/Cherry生图-01-端点类型图像生成.svg)

## 方式一：内置「绘画」页（日常 1K）

1. 顶部 **「+」** → 启动台 → **绘画**
2. 选择服务商与图像模型
3. 输入提示词
4. 调整尺寸 / 质量 / 比例 / 数量
5. 点击生成

### 分辨率 / 尺寸

| 常见选项 | 用途 |
| --- | --- |
| 自动 | 先跑通 |
| `1024x1024` | 最常用 |
| `1024x1536` / `1536x1024` | 竖图 / 横图 |
| `1024x1792` / `1792x1024` | 更长边 |

绘画页常见枚举往往到不了 4K。

### 质量 Quality

| 选项 | 说明 |
| --- | --- |
| auto | 默认 |
| low / medium / high | 采样精细程度 |

**质量 ≠ 分辨率。** `high` 不会自动变成 4K。

### 比例

常见：`1:1`、`3:4`、`4:3`、`9:16`、`16:9`、`21:9`。  
有的界面用像素尺寸间接表达比例。

## 方式二：手动设置 4K（推荐要高清时）

适用于 Gemini / 同类对话生图模型。

1. 新建或编辑助手（如「4K生图助手」）
2. 选择支持生图的模型
3. 自定义参数中添加两个 JSON 参数（见下方）
4. 保存后，在对话里发送画图指令
5. 右键查看图片属性，确认是否达到 4K 档

**参数 1：`imageConfig`**

```json
{
  "aspectRatio": "9:16",
  "imageSize": "4K"
}
```

**参数 2：`responseModalities`**

```json
["TEXT", "IMAGE"]
```

### 常用值

- `imageSize`：`1K` / `2K` / `4K`  
- `aspectRatio`：`1:1`、`2:3`、`3:2`、`3:4`、`4:3`、`9:16`、`16:9`、`21:9`  

建议拆两个助手：日常聊天用 1K；出图专用 4K，避免一直按高清计费。

![自定义参数 imageConfig=4K](/screenshots/Cherry生图-02-自定义参数4K.svg)

![出图后查看分辨率属性](/screenshots/Cherry生图-03-查看图片分辨率.svg)

## 两种方式怎么选

| | 绘画页 | 对话 + 自定义参数 |
| --- | --- | --- |
| 上手 | 简单 | 多几步 |
| 4K | 基本不行 | 推荐 |
| 适合 | 日常配图 | 壁纸 / 海报 |

<Aside type="caution">
	4K 更慢、更费额度。先用 1K/2K 验证提示词，再开 4K。
</Aside>

## 常见问题

- **绘画页没有模型**：端点类型改为「图像生成（OpenAI）」  
- **调不出 4K**：改用本页「方式二」  
- **quality=high 仍不够清**：请提高 `imageSize`，不要只调质量
