## 占位符

| 占位符 | 含义 |
| --- | --- |
| `{{API_BASE_URL}}` | API 根地址 |
| `{{API_BASE_URL}}/v1` | OpenAI 兼容常见地址 |
| `{{MODEL_NAME}}` | 完整模型名 |

若使用推荐服务 Sivyer，根地址一般为 `https://www.sivyer.cc`（仅作示例；正文其他章节仍用占位符）。

## 4K 参数速查（仅 Gemini 助手生图）

`gpt-image-*` 走绘画页，调不出该参数。Gemini 助手自定义参数：

```json
// imageConfig
{ "aspectRatio": "9:16", "imageSize": "4K" }
```

```json
// responseModalities
["TEXT", "IMAGE"]
```

完整对照见 [Cherry Studio 生图](/clients/cherry-studio-image/)。
