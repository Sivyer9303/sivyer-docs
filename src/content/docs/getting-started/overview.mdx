## 文档定位

本站提供 **通用 AI 工具使用文档**，覆盖：

- 基础环境：Node.js / npm  
- 配置管家：AI Toolbox（推荐）、CC Switch、Codex++  
- 编程助手：Claude Code（CLI / 桌面版）、Codex（CLI / 桌面版）、Cursor、Gemini CLI、ZCode  
- Agent：OpenClaw、Hermes、OpenCode、DeepSeek Harness  
- 桌面客户端：Cherry Studio、Chatbox、DeepChat  

你只需要准备两样东西，就能按教程接入大多数工具：

| 项目 | 说明 | 示例写法 |
| --- | --- | --- |
| Base URL | API 服务根地址 | `{{API_BASE_URL}}` |
| API Key | 调用凭证 | `sk-xxxxxxxx` |

## 占位符约定

全文出现以下占位符时，请自行替换：

- `{{API_BASE_URL}}`：你的 API 根地址（一般**不要**带 `/chat/completions`）  
- `{{API_BASE_URL}}/v1`：部分 OpenAI 兼容客户端需要带 `/v1`  
- `{{MODEL_NAME}}`：服务商定价页/模型列表中的完整模型名  

## 配置文件路径约定

文档里常见的 `~/某目录/...` 表示**用户主目录**下的路径（不是项目目录）：

| 写法 | 含义 |
| --- | --- |
| macOS / Linux | `~/.claude/settings.json`（`~` 即 `$HOME`） |
| Windows | `%USERPROFILE%\.claude\settings.json`（资源管理器地址栏可直接粘贴；PowerShell 里用 `$env:USERPROFILE\.claude\settings.json`） |

多数工具在 Windows 上仍使用「用户主目录下的点目录」（如 `.claude`、`.codex`），与 macOS / Linux 目录名一致，只是盘符与分隔符不同。文中若只写了 `~/...`，按上表换成 Windows 写法即可。
