建议按这个清单打勾：

1. [ ] 能登录 [https://www.sivyer.cc](https://www.sivyer.cc)
2. [ ] 账户有余额
3. [ ] 已创建 Key，且 **分组选对**
4. [ ] 客户端 / CLI 中的地址是 `https://www.sivyer.cc`（或带正确的 `/v1`）
5. [ ] API Key 粘贴完整，没有少字符、没有前后空格
6. [ ] 模型名与定价页/模型广场完全一致
7. [ ] 测试对话能收到回复
8. [ ] （可选）Cherry Studio「绘画」能出图，或 4K 助手自定义参数生图成功
9. [ ] 控制台用量/日志有新增消耗（可选确认）
