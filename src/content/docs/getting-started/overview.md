简单理解：

- **中转站** = 一个「统一的 AI 接口大门」
- 你不需要分别去申请 OpenAI、Claude、Gemini 等多个官方账号
- 只需要在本站充值 / 获取额度，创建一个 **API Key（令牌）**
- 然后把「中转站地址 + API Key」填进各种 AI 工具里即可使用

本站基于开源项目 **NewAPI**，首页已标明可适配：

- **Cherry Studio**（聊天 + **文生图** 客户端，适合日常提问、写作、出图）
- **CC Switch**（配置切换工具，适合 Claude Code / Codex 等编程 CLI）
