## 你需要准备什么

无论用哪家服务商，后续工具教程都需要：

1. **站点地址（Base URL）**  
2. **API Key（令牌）**  
3. **可用额度 / 余额**  
4. （可选）知道自己要用的 **模型名** 与 **分组**

### 注册与登录

<Steps>

1. 打开 [https://www.sivyer.cc](https://www.sivyer.cc)
2. 点击右上角登录 / 注册
3. 完成账号创建并进入控制台（Console）

</Steps>

![注册/登录入口](/screenshots/获取API-02-登录入口.png)

### 充值（卡密兑换）

本站充值流程是：**先到卡网购买卡密，再到站内钱包兑换**，不是在站内直接在线支付。

<Steps>

1. 按站点指引打开卡网 / 发卡页面，购买所需面额的卡密（兑换码）
2. 回到 Sivyer 控制台，进入 **钱包 / 充值 / 余额** 相关入口
3. 选择 **兑换码 / 卡密兑换**，粘贴刚购买的兑换码并确认
4. 确认余额已到账后再继续创建 Key

</Steps>

### 拿到 Base URL

对本推荐站点，API 根地址一般为：

```text
https://www.sivyer.cc
```

部分 OpenAI 兼容客户端需要：

```text
https://www.sivyer.cc/v1
```

在其他工具教程中，请把它们对应写成你自己的 `{{API_BASE_URL}}` / `{{API_BASE_URL}}/v1`。
