## 文档怎么读

1. 先完成「开始使用」拿到 Key  
2. 要用 npm 安装的 CLI / Agent 时，先完成 [安装 Node.js 与 npm](/basics/nodejs-npm/)  
3. 若用多个 CLI / Agent，优先装 [CC Switch](/config-manager/cc-switch/)；若主用 Codex 桌面端，看 [Codex++](/config-manager/codex-plus-plus/)  
4. 再打开你真正使用的工具章节  
5. 正文里的 `{{API_BASE_URL}}` 请替换成你的服务商地址
